# Twitch Streak

自動幫你續 Twitch 連觀的瀏覽器插件，支援 Chrome 和 Firefox（桌面版 140 以上）。

到 [最新版本](https://github.com/jaaoStudio/twitch-streak-releases/releases/latest) 下載：

- **Firefox**：用 Firefox 點 `.xpi` 檔直接安裝，之後會自動更新。
- **Chrome**：下載 `chrome.zip`，照裡面的 `README.txt` 安裝。

完整使用說明見每個版本附的 `README.txt`。

這個倉庫只放安裝檔；`updates.json` 是 Firefox 自動更新用的，請勿手動修改。
