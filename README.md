# Twitch Streak

自動幫你續 Twitch 連觀、掛台累積忠誠點數的瀏覽器插件，支援 Chrome 和 Firefox（桌面版 140 以上）。

- **Chrome**：到 [Chrome 線上應用程式商店](https://chromewebstore.google.com/detail/twitch-streak/dkfnipgnljackifggehioonkokejpjof) 按「加到 Chrome」，之後會自動更新。
- **Firefox**：到 [最新版本](https://github.com/jaaoStudio/twitch-streak-releases/releases/latest) 用 Firefox 點 `.xpi` 檔直接安裝，之後會自動更新。

完整使用說明見每個版本附的 `README.txt`。

這個倉庫放 Firefox 安裝檔；`updates.json` 是 Firefox 自動更新用的，請勿手動修改。
